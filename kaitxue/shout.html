🔊 怎么让直播间的孩子控制小魔星
正在检测你的系统…

🪟 方式 A：直接抓整个系统的声音 —— Windows 专属，最省事

Windows 的 Chrome 支持抓整个系统的声音，所以不管直播平台是网页还是客户端软件 （钉钉 / 腾讯会议 / CCtalk / 抖音直播伴侣…）都能直接抓到，不用装任何东西。
  1. 让直播平台正常播放孩子的声音（能从音箱听见就行）。
  2. 回到本页，点 「🔊 直播声音」。
  3. 在弹窗顶部选 「整个屏幕 / Entire Screen」 这一栏，点中那个屏幕缩略图。
  4. ⚠️ 关键：把左下角的 「共享系统音频 / Share system audio」 开关打开，再点「分享」。
关于音效：抓整个屏幕时，游戏自己的音效一定会被一起抓进去（系统混音没法排除单个程序）。 这个游戏已经自动处理了 —— 检测到你抓的是「整个屏幕」会自动静音游戏音效； 即使你手动把音效开回来，游戏也知道自己什么时候在响，那一瞬间不会把音量算成孩子的喊声。 所以你不用管这件事。
💡 想保留游戏音效的话：如果你的直播平台是网页，改用下面的方式 C（抓标签页）， 只抓直播那一个标签页的声音，游戏音效根本不会进来。
注意：选「窗口 / Window」是抓不到声音的（Windows 的 Chrome 只有「整个屏幕」和 「标签页」两种能带音频），一定要选「整个屏幕」。

🪟 方式 B：立体声混音（Stereo Mix）

不想每次都弹共享窗口的话，可以用声卡自带的回环通道，一次设置长期有效：
  1. 右键任务栏喇叭图标 → 「声音设置」 → 拉到底点 「更多声音设置」 → 切到 「录制」 选项卡。
  2. 在空白处右键，勾选 「显示禁用的设备」，找到 「立体声混音 / Stereo Mix」，右键 → 启用。
  3. 回到本页，把 「输入设备」 下拉框选成 「立体声混音」，再点 「🎤 麦克风」。
  4. 同样建议把 「🔊 音效」 关掉。
部分笔记本声卡（尤其是新款）没有这个选项，找不到就用方式 A。

🪟 方式 C：只抓 Chrome 标签页 —— 想保留游戏音效就用这个

如果直播平台就是个网页，点「🔊 直播声音」→ 选 「Chrome 标签页」 → 选中直播那个标签页 → 打开 「分享标签页音频」。
好处是只抓直播那一个标签页的声音，游戏音效完全不会进来， 「叮」的加分反馈可以照常开着，孩子玩起来更带劲。

🍎 方式 A：直播平台在 Chrome 网页里 —— 最推荐

  1. 先在 Chrome 里打开你的直播平台网页，让孩子的声音正常播放出来。
  2. 回到本页，点 「🔊 直播声音」。
  3. 在弹出的窗口里选 「Chrome 标签页」 → 选中直播平台那个标签页。
  4. ⚠️ 关键：左下角的 「分享标签页音频」 开关一定要打开，再点「分享」。
选好后顶部「声源」标签会变绿显示"直播声音"，孩子一开麦灯条就会跳。

🍎 方式 B：直播平台是客户端软件（钉钉 / 腾讯会议 / CCtalk 等）

macOS 的 Chrome 不能抓整个系统的声音（这是苹果系统的限制，Windows 才可以）， 需要装一个免费虚拟声卡把声音"绕"回来：
  1. 安装免费开源的 BlackHole 2ch（搜索 BlackHole audio macOS 即可）。
  2. 打开系统自带的「音频 MIDI 设置」，新建一个 「多输出设备」，同时勾选你的扬声器和 BlackHole 2ch。
  3. 把 macOS 的声音输出设为这个「多输出设备」——这样你自己能听见，声音同时也进了 BlackHole。
  4. 回到本页，把上面的 「输入设备」 下拉框选成 BlackHole 2ch，再点「🎤 麦克风」。
  5. 建议同时点一下 「🔊 音效」 把游戏音效关掉，防止游戏自己的音效也被当成孩子的喊声。

😌 懒人方案 —— 直接用麦克风收音箱

什么都不用装：把电脑音量开大，让孩子的声音从音箱放出来，用 「🎤 麦克风」 直接收。
缺点是会连教室环境音一起收进来，建议先点「🔧 校准」扣掉底噪，再用「灵敏度」微调。

🔀 两路声源是「二选一」，切换不用手动关

「🎤 麦克风」和「🔊 直播声音」同一时间只会开一路。
你自己开麦做完演示，直接点「🔊 直播声音」就行 —— 麦克风会自动关掉， 顶部会提示一句，不用担心忘记关麦导致两路声音一起进来互相干扰。
想彻底关掉声源，再点一次当前那个亮着的按钮即可。

✅ 上课前 30 秒自检

让一个孩子在直播间喊一声，看顶部灯条有没有亮：
亮得太少 → 把「灵敏度」往右拖；
没喊也一直亮 → 点「🔧 校准」（保持安静 2 秒）。
