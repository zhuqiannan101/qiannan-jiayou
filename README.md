# 课导培训刷题中心

图形化课导新人培训刷题系统 —— 每天随机 30 题，单选 / 多选 / 判断 / 填空混合出题，刷一道记一道。

## 在线刷题

> 开启 GitHub Pages 后访问：`https://<用户名>.github.io/<仓库名>/`

## 使用说明

1. 首页选择 Day1 / Day2 / Day3 进入对应天数的刷题
2. 每轮从当天全部题库随机抽 30 题（同轮题干不重复）
3. 题型完全混合，不可筛选——做题前不知道题型，更接近真实考核
4. 每答完一题立即显示正确答案与解析，刷一道记忆一道
5. 填空题答案自动容错：忽略空格与标点，支持多个等义答案
6. 答完可「换一批」无限刷，直到稳定 80 分以上

## 业务线分流（2026-11-05 上线）

S 业务体系两条独立业务线：**科特线、思维线**。学员首次进入需登记姓名与业务线（锁定），D1 通识与赛考模块按线路过滤出题，其余模块通用混刷：

| | 科特线 | 思维线 |
|---|---|---|
| 等级考试 | CTL | YCL |
| 赛事 | 图灵杯 | — |
| 证书规划 | 1 年 4 张国家级证书 | 半年 YCL1 级 / 1 年 3 张 |
| 课时 | 60 课时（软编 30+硬编 12+赛事课 12+赛事直播 6） | 48 课时（软编 42+硬编 6） |
| 解锁规律 | 第 4 周加密（周日加赛考课/赛事直播） | 每周 1 次全年不加密，硬编隔月第三周 |


- 刷题/考试均按线别出题，另一条线专属题不可见；「重置身份」可切换（管理员场景）
- 双线对比类题目保留为通用，两线学员都要掌握
