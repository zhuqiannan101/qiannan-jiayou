# 课导培训刷题中心

图形化课导新人培训刷题系统 —— 每天随机 30 题，单选 / 多选 / 判断 / 填空混合出题，刷一道记一道。

## 在线刷题

> 开启 GitHub Pages 后访问：`https://<用户名>.github.io/<仓库名>/`

## 题库总览

| 刷题口 | 课程范围 | 题库规模 |
|--------|----------|----------|
| **Day1** | 课导工作流程 + 首通电话 + 课程体系 | 158 题 |
| **Day2** | 直播基本功 + 异议处理 + 为什么学少儿编程 | 135 题 |
| **Day3** | 图形化赛考体系（履约重点） | 108 题 |

合计 401 题，含 58 道填空题。

## 使用说明

1. 首页选择 Day1 / Day2 / Day3 进入对应天数的刷题
2. 每轮从当天全部题库随机抽 30 题（同轮题干不重复）
3. 题型完全混合，不可筛选——做题前不知道题型，更接近真实考核
4. 每答完一题立即显示正确答案与解析，刷一道记忆一道
5. 填空题答案自动容错：忽略空格与标点，支持多个等义答案
6. 答完可「换一批」无限刷，直到稳定 80 分以上

## 部署（GitHub Pages）

3. Branch 选择 `main` / `(root)` → Save
